# ICT Secondary — أولى ثانوي · الترم الأول

منصة تعليمية احترافية لمادة تكنولوجيا المعلومات والاتصالات (ICT) للصف الأول الثانوي — الترم الأول، مبنية على منهج وزارة التربية والتعليم (كتاب «البرمجة والذكاء الاصطناعي — مقدمة في تكنولوجيا المعلومات والاتصالات 2025–2026»).

## المميزات

### 1) الدروس
- 11 وحدة و40 درسًا مع أهداف، شرح، نقاط أساسية، أمثلة محلولة، ومهمة تطبيقية.
- اختبار قصير (Quiz) بعد كل درس مع تصحيح فوري وشرح سبب الإجابة.
- تتبّع التقدم + شهادات رقمية قابلة للطباعة (محليًا، ومع الحسابات بيتزامن مع السيرفر).

### 2) المعامل التفاعلية (10 معامل)
جرّب بنفسك بدل ما تقرأ بس:
- 🔐 **معمل التشفير** — شفرة قيصر للنص العربي والإنجليزي مع خريطة الحروف.
- 🔑 **مقياس قوة كلمة المرور** — مؤشر فوري على 6 قواعد أمان.
- 💠 **محوّل الأنظمة العددية** — عشري ↔ ثنائي ↔ ست عشري + رموز الأحرف (ASCII).
- 🎚️ **تناظري → رقمي (ADC)** — موجة تفاعلية تتحوّل لبتات 0/1 حسب معدّل العينات.
- ⚡ **البوابات المنطقية** — AND/OR/NOT/NAND/NOR/XOR مع جدول الحقيقة.
- 🌐 **محاكي DNS** — رحلة اسم النطاق حتى عنوان IP خطوة بخطوة.
- 📊 **مستكشف البيانات** — إحصاءات ورسوم بيانية (أعمدة/خطي) تتحدّث لحظيًا.
- 🧪 **محاكاة النمو السكاني** — غيّر معدّل النمو والسنين وشوف النتيجة.
- 🏠 **المنزل الذكي (IoT)** — شغّل الأجهزة وراقب استهلاك الكهرباء.
- 🤖 **كيف يتعلّم الذكاء الاصطناعي** — «درّب» نموذجًا يستخرج أفضل خط من بيانات مشوّشة.

### 3) الألعاب والتحديات (5 ألعاب)
- 🧩 وصّل المصطلح · ⚡ صح أم خطأ · 🔢 رتّب الخطوات · 🐍 خمّن الرقم · 🔍 محقق البيانات.
- كل لعبة تمنح نقاطًا تنضم لرصيدك في الملف الشخصي.

### 4) المشاريع
- 29 فكرة مشروع موزّعة على الوحدات (خطوات + وسوم موضوعية)، وتظهر أيضًا داخل كل وحدة.
- **ديمو لكل مشروع** («شوف النتيجة»): نافذة تعرض الناتج النهائي المتوقّع:
  - **ديمو تفاعلي** للمشاريع البرمجية (حاسبة الدرجات، مدير المهام، جدول المكتبة، تصنيف الوسائط، محاكاة الطابور، توصيل البروتوكولات).
  - **إعادة استخدام معمل/لعبة** جاهزة (التشفير، الأنظمة العددية، ADC، البوابات، DNS، البيانات، المحاكاة، المنزل الذكي، خمّن الرقم).
  - **«شكل الناتج»** للمشاريع الورقية (بوسترات، وثائق، جداول، خطوط زمنية، مخططات، واجهات).

### 5) المدرّس الذكي (AI Tutor)
- شات جوه كل درس: «اشرح تاني»، «لخّص»، «مثال جديد»، أو اسأل أي سؤال.
- يشتغل بوضعين:
  - **متصل**: عبر خادم الذكاء الاصطناعي (`/api/tutor`) بإجابات من مُدرّب بشخصية مدرّس مصري مبسّط.
  - **وضع محلي**: لو مفيش مفتاح/خادم، يجيب من محتوى الدرس نفسه (ملخص، شرح، أمثلة) بدون أي انقطاع.

### 6) الحسابات ولوحة المدرس
- **تسجيل الطالب**: الاسم + رقم الموبايل + الصف + كلمة مرور (٦ حروف على الأقل).
- الحساب بيتحوّل لحالة **«معلّق»** لحد ما المدرس يفعّله — **والمنصة كلها مقفولة** لحد التفعيل (مفيش دروس ولا اختبارات ولا مدرّس ذكي).
- **لوحة المدرس**: كل الحسابات، بحث وفلترة (الكل/معلّق/مفعّل/موقوف)، وتفعيل/إيقاف/تصفير أجهزة/حذف.
- **تجديد كلمة المرور**: لو الطالب نسيها، المدرس يعمل كلمة مرور جديدة (مولّدة أو مكتوبة) وتظهر له جاهزة للنسخ.
- **حد الأجهزة**: جهازان لكل حساب. لو دخل جهاز ثالث، **الأقدم بيخرج تلقائيًا** برسالة واضحة للطالب.
- **تسجيل الخروج**: زرار في الشريط العلوي + جوه الملف الشخصي + من شاشة الحساب.
- **التحليلات**: إجمالي/مفعّل/معلّق/موقوف، أجهزة نشطة، جديد آخر ٧ أيام، رسم بياني لآخر ١٤ يوم (دخول + طلاب نشطين)، الأنشطة، أكتر الدروس فتحًا، أعلى الطلاب، الطلاب المتوقفين، متوسط درجات الاختبارات، وعدد أسئلة المدرّس الذكي.
- النشاط بيتسجّل تلقائيًا: تسجيل/دخول، درس، اختبار (مع الدرجة)، معمل، لعبة، ديمو، إكمال وحدة، وأسئلة المدرّس الذكي.

> **ملاحظة أمانة:** الملفات الثابتة للمحتوى (`data-units-*.js`) بتتقدّم كملفات عادية، فممكن حد تقني ينزّلها ويدوس على الرابط مباشرة.
> اللي محمي فعليًا هو **المنصة نفسها**: كل الواجهة والدوال (`/api/tutor`، المزامنة، التحليلات) بترفض أي طلب من غير حساب مفعّل.

## تشغيل الحسابات (Supabase — مجاني 100% وبدون كارت)

من غير Supabase الموقع بيشتغل عادي بس **من غير تسجيل** (وضع مفتوح). لتشغيل الحسابات:

1. اعمل حساب على https://supabase.com (تسجيل بحساب GitHub — بدون كارت).
2. **New project** → اختار اسم وكلمة مرور قوية للداتابيز → **Create**.
3. من **SQL Editor → New query** الصق محتوى ملف `supabase-schema.sql` ودوس **Run**.
4. من **Settings → API** انسخ:
   - **Project URL** → `SUPABASE_URL`
   - **service_role** key (سرّي جدًا) → `SUPABASE_SERVICE_KEY`
5. حطهم في `.env` محليًا، و/أو في **Environment Variables** على Vercel، وبعدها اعمل Redeploy.

> ⚠️ مفتاح `service_role` **مابيظهرش في المتصفح أبدًا** — بيتقرأ على السيرفر بس. الجداول عليها RLS من غير أي سياسات، يعني محدش يقدر يوصلها غير بمفتاح السيرفر.

### متغيّرات البيئة المطلوبة للأدمن
```
SUPABASE_URL=...              # مشروعك على Supabase
SUPABASE_SERVICE_KEY=...      # service_role key
ADMIN_USER=admin              # اختياري (الافتراضي admin)
ADMIN_PASSWORD=...            # كلمة مرور قوية للوحة المدرس (إجباري)
SESSION_SECRET=...            # نص عشوائي طويل (بيوقّع جلسة الأدمن)
```
- **الأدمن بيدخل باسم مستخدم + كلمة مرور** (مفيش إيميل في النظام خالص — الطلاب بيسجّلوا برقم الموبايل).
- لو `ADMIN_PASSWORD` مش موجود، اللوحة بتقول «لوحة المدرس مش مفعّلة» ومبتفتحش.
- تغيير `SESSION_SECRET` بيخرج أي أدمن مسجّل فورًا.
- بيتنسخ من `.env.example`.

## التشغيل

### أ) تشغيل سريع (بدون ذكاء اصطناعي)
```bash
cd ict-sec1
python -m http.server 8010
# افتح: http://localhost:8010
```
كل حاجة هتشتغل، والمدرّس الذكي هيشتغل بالوضع المحلي.

### ب) تشغيل كامل (مع المدرّس الذكي)
```bash
cd ict-sec1
npm start            # أو: node server.mjs
# افتح: http://localhost:4173
```
1. انسخ `.env.example` إلى `.env` (جوه مجلد المشروع) وحط المفتاح:
```
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.8-flash
# اختياري: GEMINI_FALLBACK_MODELS=gemini-3.5-flash,gemini-flash-latest
# اختياري: AI_PROVIDER=openai + OPENAI_API_KEY
```
   الخادم بيقرا `.env` من مجلد المشروع، ولو ملقاهوش بيجرّب المجلد الأعلى (`../.env`).
2. الخادم يجرّب الموديل المحدّد، ولو الحد المجاني خلص أو الموديل غير متاح، ينتقل تلقائيًا لموديلات بديلة ويتذكّر آخر موديل شغّال لتقليل زمن الرد.
3. لو مفيش مفتاح: `/api/health` يرجّع `{"ready":false}` والواجهة تستخدم الوضع المحلي.

> ⚠️ **مهم:** المدرّس الذكي بيشتغل لما تفتح الصفحة من خادم المشروع نفسه (`http://localhost:4173`). لو فتحتها من سيرفر ملفات ثابتة (زي `python -m http.server`) أو من `file://`، مش هيكون فيه `/api/tutor` والواجهة هتعرض **«وضع محلي»**.

## النشر (عشان المدرّس الذكي يشتغل أونلاين)

**GitHub Pages لوحده مش كفاية** — بيقدّم ملفات ثابتة بس (مفيش Node)، فالـ AI هيرجع «وضع محلي». لازم استضافة بتشغّل Node.

### Vercel (مجاني 100% · بدون كارت) — الموصى به
1. ادخل https://vercel.com وسجّل بحساب GitHub.
2. **Add New → Project** → اختار ريبو **`shadi2017/ict-sec1`** → **Import**.
3. في **Environment Variables** ضيف:
   - `GEMINI_API_KEY` = المفتاح بتاعك
   - (اختياري) `GEMINI_MODEL` = `gemini-3.8-flash`
   - **لتشغيل الحسابات**: `SUPABASE_URL` · `SUPABASE_SERVICE_KEY` · `ADMIN_PASSWORD` · `SESSION_SECRET` (وشوف قسم «تشغيل الحسابات» فوق)
   - **ملحوظة**: من غير متغيّرات Supabase الموقع هيشتغل في **الوضع المفتوح** (بدون تسجيل) — مش هيتقفل.
4. دوس **Deploy** — هتاخد رابط زي `https://ict-sec1.vercel.app`.
5. افتح الرابط: `/api/health` هيرجّع `{"ready":true}` والمدرّس هيبقى **متصل**.

- الملفات الثابتة بتتقدّم من جذر الريبو، والدوال في مجلد `api/` (`/api/tutor` و`/api/health`).
- المفتاح بيتحط في إعدادات Vercel بس — **مش بيترفع** على GitHub.
- كل `git push` على `main` بيعيد النشر تلقائيًا.
- دالة المدرّس ممكن تاخد لحد ~30 ثانية، وده مضبوط في `vercel.json` (`maxDuration: 30`).

> ⚠️ **مهم جدًا:** في `vercel.json` فيه `"framework": null` — ده **إجباري**.
> لو Vercel اكتشف إطار عمل تلقائيًا (زي Node) هيتوقّع مجلد `public/` أو `dist/`،
> وساعتها **كل الروابط (حتى `/styles.css`) هترجّع خطأ 500 `FUNCTION_INVOCATION_FAILED`**
> لأن مفيش ملفات ثابتة بتتقدّم خالص. `null` بتخلّي الإعداد **Other**، فيتقدّم
> الملفات من جذر المشروع زي ما هو مطلوب.
>
> ولو حصل نفس الخطأ تاني: اتأكد من **Settings → Build & Development Settings**
> إن **Framework Preset = Other**، و**Root Directory** فاضية، و**Output Directory** فاضية.

#### حل مشكلة 500 `FUNCTION_INVOCATION_FAILED` (لو رجعت تاني)
1. **Build Logs** → اتأكد إن البناء نجح ومفيش رسالة `No Output Directory named "public" found`.
2. **Runtime Logs** → دي بتوريك الخطأ الحقيقي جوه الدالة (مثلاً `Cannot find module`).
3. اتأكد إن `GEMINI_API_KEY` مضاف في **Settings → Environment Variables** (لازم تعمل Redeploy بعد إضافته).
4. من سطر الأوامر (بعد `npx vercel login`): `npx vercel logs --request-id <ID>`.

### Render (مجاني، لكن بيطلب كارت للتحقق من الهوية)
1. في Render: **New → Blueprint** → اختار ريبو `shadi2017/ict-sec1` (ملف `render.yaml` موجود وجاهز).
2. وقت الإعداد هيطلب منك القيم السرّية — حط:
   - `GEMINI_API_KEY` = المفتاح بتاعك (من https://aistudio.google.com/apikey)
3. دوس Deploy، وهتاخد رابط زي `https://ict-sec1.onrender.com`.
4. افتح الرابط — `/api/health` هيرجّع `{"ready":true}` والمدرّس هيبقى **متصل**.

- المفتاح **مش بيترفع** على GitHub (ملف `.env` متجاهل) — بيتحط في إعدادات الاستضافة بس.
- الخطة المجانية بتنام بعد خمول، فأول فتح بعد فترة ممكن ياخد ~30 ثانية.

## النسخ الاحتياطي اليومي (Supabase → تليجرام + Drive + إيميل)

- كل يوم **1:00 ص** بتوقيت القاهرة، GitHub Actions بيشغّل `tools/backup/backup.mjs`.

  **[tools/backup/README.md](tools/backup/README.md)**.

## معمارية الواجهة
- **render-from-state**: كل تفاعل يعدّل `state` ثم يعيد بناء الواجهة — فلا تتعارض الحالة مع العرض (اللغة/الثيم/التنقّل).
- الأقسام: `lessons` · `labs` · `games` · `projects` من خلال `ICT.setView()`.
- واجهة برمجية عامة: `window.ICT` (openUnit/openLesson/openLab/openGame/askTutor/...).
- مفاتيح التخزين: `ict-progress-v2`, `ict-awarded`, `ict-points`, `ict-certs`, `ict-name`, `ict-theme`, `ict-lang`.

## محتوى الوحدات
1. ما هي المعلومات؟ (بيانات، معلومات، معرفة، وسائط، أخلاقيات)
2. القوانين والحقوق في مجتمع المعلومات (بيانات شخصية، خصوصية، ملكية فكرية)
3. أمن المعلومات (كلمات مرور، تشفير، توقيع رقمي، SSL/TLS)
4. تكنولوجيا المعلومات والمجتمع (ذكاء اصطناعي، إنترنت أشياء، بيانات ضخمة، واقع افتراضي/معزز)
5. الاتصالات (تطوير وسائل الاتصال، ثنائي وست عشري)
6. الكمبيوتر (مكونات، عتاد وبرمجيات، دوائر منطقية)
7. الشبكات (IP، DNS، بروتوكولات، ويب، بريد إلكتروني)
8. قواعد البيانات
9. تحليل البيانات
10. المحاكاة والنمذجة
11. البرمجة بلغة بايثون (خوارزميات، متغيرات، حلقات، قوائم، دوال، شروط)

- زر اللغة (`EN` / `ع`) يبدّل **المحتوى بالكامل** — مش الواجهة بس:
  - عناوين الوحدات والدروس، الأهداف، شرح الدرس، النقاط الأساسية، الأمثلة، المهمة التطبيقية.
  - أسئلة الاختبارات وخياراتها وشرح الإجابة.
  - المشاريع (الوصف والخطوات) وديموهاتها.
  - نصوص المعامل والألعاب من الداخل.
  - إجابات المدرّس المحلي + لغة ردّ المدرّس الذكي.
- المحتوى العربي هو الأصل، والإنجليزي في ملفات `data-en-*.js` (طبقة ترجمة مستقلة تُحمَّل فوق العربية، وترجع للعربية تلقائيًا لو أي حقل ناقص).
- عند التبديل للإنجليزية يتحوّل اتجاه الصفحة تلقائيًا إلى LTR.
